An invented passport spread for the Republic of Zembla — a data page with a portrait and a machine-readable strip with correct check digits, a single-entry Talveria visa (employment prohibited, 40 kr fee paid), and arrival/departure stamps from neighbouring Karvostan and Talveria that agree with the passport's issue and expiry dates. Drawn by `generate.py`, written out by `main.py`.

## Run it

```sh
python3 main.py
```

Writes the passport spread image to `/output/entry.png`.
